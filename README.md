# 校园二手交易系统需求分析

软件工程实验一的作业。项目面向校园闲置物品交易，主要考虑商品发布、审核、查询、预约和成交确认，也整理了举报、日志、统计及异常处理的要求。本次只做需求分析，不实现软件，也不接入支付和物流。

## 文件说明

- `requirements.md`：完整需求清单，共24条，包含20条功能需求和4条非功能需求。
- `chat.txt`：访谈、AI交互和审查记录。

实验报告另行提交，不放在仓库里。

## 版本记录

`lab1-ai-draft` 保存首轮需求，`lab1-final` 保存确认后的需求和完整记录。两个阶段按整理后的实验材料归档，标签保持不变，可以直接在 GitHub 上切换查看。
