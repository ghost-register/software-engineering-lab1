# 软件工程实验二

沿用校园二手交易系统，设计保存在本目录。UML目录有六种PlantUML图的源码与PNG，UI界面目录有18个Figma导出页面；UI源文件提供SVG、构建代码和可编辑设计链接。

设计说明记录模块、接口、事务与需求对应；过程记录分别保存用户真实反馈、AI辅助与自动校对。本目录提供实验报告的Word与PDF版本，界面可通过[原Figma文件](https://www.figma.com/design/en6DAOl7x9I8Qmu6BFwsOv)继续编辑。

实验一已有文件与标签保持不变，若后续需求确有变化，再单独修改并记录原因，详见过程记录中的实验一到实验二变更记录。
