# 可编辑界面设计

Figma文件：https://www.figma.com/design/en6DAOl7x9I8Qmu6BFwsOv

一个页面中保存UI01至UI18，全部为原生可编辑文字、布局和组件实例；未把整页截图贴进设计画布。按钮与输入框复用Simple Design System，正文采用Noto Sans SC。Figma已导出18张1440×1080 PNG和18份SVG，分别保存在UI界面与本目录SVG中。

Figma构建脚本.js为本次构建逻辑的完整本地副本，需要在支持Figma Plugin API的设计文件上下文中执行；不是运行网站的业务实现。界面清单.json保存页面用途与需求编号。商品图片区采用文字示意，非真实商品照片；界面数字为演示数据。

MCP工具在批量导出时达到Starter额度，后改用编辑器正常批量导出，不绕过账户限制或要求升级。源设计与全部PNG/SVG均保留。
